# Dataset Construction

## Prerequisites

This module requires code from the [DNE](https://github.com/rui-yan/DNE) repository.

## Setup

Clone the DNE repository into this directory:

```bash
cd src/dataset_construction
git clone https://github.com/rui-yan/DNE.git
```

After cloning, your folder structure should look like this:
```bash
dataset_construction/
├── README.md
├── DNE/
│   ├── code/
│   │   ├── models/
│   │   │   ├── dne.py
│   │   │   └── ...
│   │   ├── utils/
│   │   │   └── ...
│   └── ...
└── ...
```

> **Note:** The `DNE/` folder is not included in this repository due to its
> [CC BY-NC-ND 2.0](https://creativecommons.org/licenses/by-nc-nd/2.0/) license.
> Please clone it directly from the [original source](https://github.com/rui-yan/DNE).
