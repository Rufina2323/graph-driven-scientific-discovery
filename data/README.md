# Data Directory

The full data archive is hosted on Yandex.Disk.

## Steps to download

1. Open the following link in your browser:
```bash
https://disk.yandex.ru/d/JsG28eNwXEGMLA
```
2. Click **Download** to get the ZIP archive.

3. Extract it into this directory so that the folder structure looks like this:

```bash
data/
├── raw/                   ← original paper data
├── extracted_concepts/    ← outputs of the extraction stage
└── link_prediction/       ← outputs of model training and link prediction stages
